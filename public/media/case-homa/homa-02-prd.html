一、需求背景

奥马冰箱国内营销中心的视觉设计岗，在新品上市、大促与平台热点等高密度节点，需要在数天内产出覆盖小红书首图、抖音封面、电商主图与视频号封面的全套视觉物料，并同步承担短视频剪辑全流程。目前每位设计同学需独立制作产品主图、详情页、场景图、营销海报与宣传物料，产能完全依附于个人工时。

直接后果是：供给跟不上节点——素材产出速度追不上内容消耗速度，临近上市只能降低产出数量或压缩精修质量；长期后果是国内认知差填不上——奥马连续 17 年蝉联中国冰箱出口冠军、累计销量超 1.5 亿台，但国内端被媒体评价为「没有铺天盖地的营销宣传」，出口端的产品优势没有被翻译成消费者听得懂的平台内容。同期竞品已跑通「内容种草 + 直播下单」的闭环，并形成了以「594mm 零嵌」「母乳 4℃ 专舱」为代表的可复用消费者语言。

事实来源：职责与产能描述引自《Homa 国内营销类 · 市场经理》招聘 JD（2026-09-21 发布）；「17 年出口冠军 / 1.5 亿台」与「国内缺少大规模营销宣传」引自公开报道（新浪财经、艾肯家电网 2026 广东优品展报道）；竞品内容表现引自公开报道（容声方糖系列登顶抖音大家电榜、方糖 2.0 上市首周单品第一）。目前没有内部素材产能与投放效果的真实数据，本需求的问题判断基于上述公开信息与岗位文本，产能基线待首次使用后回填。

二、需求目标

让 1-2 人的视觉设计岗，在一个新品上市周期内稳定交付全部所需的多平台素材，并且产出的素材能被真正投放使用，而不是堆在个人文件夹里。

用户结果衡量指标统计口径预期方向目标值
在上市节点前凑齐内容包要求的全部素材内容包交付达成率上市前完成入库的素材数 / 内容包计划素材数↑待基线确认
单张素材不再消耗整块工时单张素材平均耗时（素材入库时间 − 任务创建时间）的中位数↓待基线确认
产出的素材能被实际投放使用素材采用率被投放使用的素材数 / 入库素材数↑待基线确认
同一卖点一次产出多平台规格，不用逐平台重做多平台一次产出率单任务同时产出多规格的素材数 / 单任务总产出数↑待基线确认
低效模板能被及时识别并淘汰待复盘模板占比处于「待复盘」状态的模板数 / 启用中模板数↓待基线确认
上述目标值一律记为「待基线确认」：缺少工具上线前的真实基线数据，本次不设定具体提升幅度。上线后由第 3.1 条口径回填，并在第二个迭代版本补充实际目标值。

三、需求概述

本期范围
  • Web 端内部工具，覆盖「新建生成任务 → AI 批量产出 → 人工精修入库 → 素材库检索复用 → 数据回流与模板迭代」完整链路，共 8 个页面。
  • 首批接入产品线：母婴健康储鲜（526 法式平嵌母婴冰箱）、嵌入式美学厨居、鸿蒙智联。
  • 首批支持规格：小红书首图 3:4、抖音封面 9:16、电商主图 1:1、视频号封面 16:9。
  • 首批用户：国内营销中心视觉设计岗，营销中心负责人仅开放查看视角。
本期不做什么 / 暂不展开
  • 不做平台的自动发布与账号矩阵管理：依赖各平台开放平台授权与合规审批，本期素材出厂后仍需人工投放。
  • 不替换 PS / PR 等专业软件：AI 产出只到候选稿，最终精修与终审仍在专业软件完成，工具不承载专业修图能力。
  • 不做公网对外开放版本：涉及品牌资产与未发布新品素材，仅限内网账号访问。
  • 不做平台侧表现数据的自动拉取：曝光、点击、互动数据本期走手动录入 + 内部统计，开放平台对接列后续。
  • 不生成含真实人物的素材外投版本：含人脸素材需额外确认肖像授权流程，本期只做检出与拦截。

状态可流转到说明
候选待选待精修 / 自动清理生成后默认状态，未选中候选保留 7 天后自动清理，清理前 1 天站内提醒责任人

已归档—仅可查看与恢复，不可直接编辑，归档后仍计入历史使用数据

判定条件处置说明
采用率低于 45%，或使用次数不足 10 次标记「待复盘」仍在可用列表，但排序降权，不再出现在推荐位

1.2 新建生成任务

打开可点击原型
【页面元素】

1、四步表单，自上而下：选择产品线（下拉单选）、选择卖点标签（多选标签组，最多 2 个）、选择平台与规格（四宫格卡片多选）、场景风格与数量（两个下拉）

2、右侧「生成配置预览」卡：内容包归属、场景模板、平台数、预计产出张数、预计耗时、本次消耗算力点数

3、右侧「合规前置校验」卡：品牌主色已锁定 / 卖点文案已过审 / 无绝对化用语 / 待补产品实拍参考图，各以标签呈现

4、底部操作区：保存为草稿、开始生成

【交互说明】

1、点击卖点标签 → 选中或取消选中，选中超过 2 个时第 3 个不可点并提示「最多同时串联 2 个卖点，避免构图元素过载」

2、完成卖点选择 → 右侧预览卡自动匹配并展示推荐场景模板名与版本号

3、勾选平台规格卡片 → 预览卡同步更新平台数、预计产出张数与消耗点数

4、点击「开始生成」 → 进入任务队列页并开始执行

5、点击「保存为草稿」 → 表单当前值存入草稿，返回工作台，草稿在工作台以「草稿」标签呈现

【功能逻辑】

1、卖点标签数量与 style（场景风格）共同决定可选模板范围：所选组合无匹配模板时，标签组下方提示「当前组合暂无模板，建议先到模板库新建」

2、预计产出 = 已选平台数 × 每个平台候选张数，任一项为 0 时「开始生成」不可点击

【前置条件与权限】

1、剩余算力额度须不小于预计消耗，否则「开始生成」置灰（见「算力额度与并发」规则）

2、合规前置校验存在「不通过」项（如检测到未过审文案）时阻断提交；仅「待补」提示项不阻断，但需在结果页提示人工关注

【边界说明】

1、未上传产品实拍参考图 → 允许生成，但在结果页顶部提示「本次未使用实拍参考，冰箱外观请重点人工核对」

2、同一账号 30 秒内重复点击「开始生成」 → 仅受理一次，避免重复消耗额度

3、草稿保留 30 天，超时自动清理并在清理前提醒一次

【交互说明】

3、点击「查看已产出」 → 进入生成结果页，仅展示已完成批次的候选

【功能逻辑】

1、批次执行顺序按用户勾选平台的先后顺序，同一任务的平台规格之间不并发，避免同任务抢占资源

2、单批次超过 10 分钟未完成 → 标记该批次为异常并释放通道，日志留痕，未消耗的批次额度自动退回

【边界说明】

1、生成过程中关闭页面 → 任务在服务端继续执行，回到任务队列页可看到进度恢复

2、某批次生成失败 → 卡片显示「失败」并提供「重试该批次」按钮，重试不额外扣点

3、并发通道满 → 新批次自动排队并在卡片显示队列位次

2、待人工确认的候选需设计师在精修页逐张确认后才能入库，不在本页放行

【文案规范】

1、合规状态标签文案固定为：合规通过 / 待人工确认 / 含人脸待处理，不随场景改写

2、空选态提示：「请至少选择 1 张候选后再进入精修」

【数据与内容规则】

1、候选编号规则：平台字母代号 + 序号（小红书=A、抖音=B、电商主图=C、视频号=D）

2、同一任务的候选默认保留 7 天，倒计时在卡组标题右侧显示

【边界说明】

1、某平台批次失败 → 该分组显示为空分组并提供「重试该规格」入口，其余分组正常操作

2、未上传实拍参考图的任务 → 本页顶部展示橙色提示条「本次未使用实拍参考，冰箱外观请重点人工核对」

3、全部候选均未选中直接点击「精修并入库」 → 按钮置灰并 Toast 提示空选态文案

打开可点击原型
【页面元素】

1、左侧预览区：大图预览、工具栏（裁剪换尺寸 / 替换文案层 / 调色 / 去瑕疵）、当前缩放比例

2、右侧「入库信息」：素材标题输入框（带默认值）、适用平台下拉、关联卖点标签组

3、右侧「发布前检查项」五条：冰箱外观与实拍一致 / 无绝对化用语 / Logo 位置与尺寸规范 / 已确认肖像或物权授权 / 参数文案与产品手册一致

4、右侧「版本与来源」表：版本号、来源模板、生成任务号、责任人

5、底部操作：存为草稿、「确认入库」主按钮

【交互说明】

1、点击工具栏任一项 → 在预览区打开对应编辑抽屉，操作仅在本地预览生效，原始候选文件保留

2、勾选检查项 → 实时更新完成计数，五项全选后「确认入库」方可点击

3、点击「确认入库」 → 素材写入素材库并生成版本号，页面跳转到素材库并高亮该条新素材

4、点击「存为草稿」 → 保留当前编辑状态，素材状态回到「待精修」

【功能逻辑】

1、检查项未全部勾选时，「确认入库」保持置灰；存在未勾选项但用户坚持入库的场景本期不开放，全部五项均为必选

2、标题默认由「产品线 + 卖点 + 平台 + 版本」自动拼接生成，可覆盖；入库时若检测到重名，自动在末尾追加序号

【前置条件与权限】

1、仅视觉设计岗可提交入库（见「角色权限矩阵」规则），营销负责人视角下本页为只读

2、来源模板已下线时仍允许入库，但需在版本来源卡标注「来源模板已下线」

【边界说明】

1、同一候选被第二个账号同时打开精修 → 后进入者看到提示「该素材正在被 X 编辑」，且只能查看不可提交

2、肖像授权检查项未勾选且素材含人脸 → 提交时额外弹二次确认，说明「未授权素材不得用于外投渠道」

3、适用平台改动后，原平台尺寸的裁剪结果失效 → 提示需重新设置裁剪

待后续确认的产品口径

  • 埋点字典与字段命名规范 —— 卡在：数据/增长侧同事；影响：第七章全部「待确认」参数需替换后才能上线。
  • 算力单价与月度额度 500 点是否为最终定价 —— 卡在：工具采购归口；影响：第 3.1 条额度规则与必备的成本核算。
  • 采用率的下游口径「被投放使用」如何判定（人工登记 vs 平台回填）—— 卡在：媒介投放同事；影响：第 2 章目标表与数据看板采用率是否可用。
  • 含人脸素材的肖像授权流程由谁审批、是否在本工具内闭环 —— 卡在：法务；影响：第 1.5 节检查项是否改为强校验。
  • 模板启停阈值 45% / 10 次是否为最终值 —— 卡在：营销负责人；影响：第 3.3 条规则与模板的下线判定。
  • 是否需要支持视频剪辑（JD 含短视频剪辑职责）—— 卡在：需求方；影响：本期范围为「图片素材」，视频能力列为下一版本评估项。
